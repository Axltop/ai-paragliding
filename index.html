Launch Window

Paragliding site scores from ECMWF, ICON and GFS forecasts, for thermal flying or ridge soaring. Each score combines wind on the launch, gusts, wind aloft, rain, cloud base, thermals and storm risk.

Add launchesSearch by name, or find launches near a town

Your sites, settings and API keys stay in this browser. This site stores nothing about you, sets no cookies and keeps no request logs.
Launch sites come from Paragliding Mapa (paragliding-mapa.cz, DHV, Paragliding Earth and XContest), the same source as the Windy plugin pg-mapa. Forecasts come from Open-Meteo, plus Windy and Meteoblue when you add API keys.
The score only supports your own judgment. It can't see rotors, local convergence or what the windsock is doing. Always check the site rules and the conditions on the hill yourself.

Wing, sources & keys

Class presets are rough trim-speed estimates, not certification performance or a recommendation to fly a higher class. Pilot wind and gust limits still apply.
Include pilot, wing, harness, reserve, clothing, ballast and all equipment. Stay within your wing's certified weight range.
Use your wing's published unaccelerated trim speed and the all-up weight it was measured at. Blank speed uses the class estimate; the default reference weight is 100 kg. Speed scales with the square root of flight weight / reference weight for the same wing size. This is only an estimate, not a measured groundspeed; speed-bar gains are not assumed.
Open-Meteo models (free, no key)
Get one at api.windy.com/keys. Trial keys return deliberately shuffled data, so use them for testing only.
Get one at meteoblue.com/en/weather-api. Keys stay in this browser only.
Your data Your sites, pilot profile, wing settings, model choices and API keys are stored only in this browser (local storage). The server that hosts this page stores nothing about you. Forecast and site lookups go straight from your browser to Open-Meteo, Paragliding Mapa, Windy and Meteoblue.
