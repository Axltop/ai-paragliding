Launch Window

Paragliding site scores from ECMWF, ICON and GFS forecasts. Each score combines wind on the launch, gusts, wind aloft, rain, cloud base, thermals and storm risk.

Your sites, settings and API keys stay in this browser. This site stores nothing about you, sets no cookies and keeps no request logs.
Launch sites come from Paragliding Mapa (paragliding-mapa.cz, DHV, Paragliding Earth and XContest), the same source as the Windy plugin pg-mapa. Forecasts come from Open-Meteo, plus Windy and Meteoblue when you add API keys.
The score only supports your own judgment. It can't see rotors, local convergence or what the windsock is doing. Always check the site rules and the conditions on the hill yourself.

Sources & keys

Open-Meteo models (free, no key)
Get one at api.windy.com/keys. Trial keys return deliberately shuffled data, so use them for testing only.
Get one at meteoblue.com/en/weather-api. Keys stay in this browser only.
Your data Your sites, pilot profile, model choices and API keys are stored only in this browser (local storage). The server that hosts this page stores nothing about you. Forecast and site lookups go straight from your browser to Open-Meteo, Paragliding Mapa, Windy and Meteoblue.
